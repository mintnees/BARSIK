# ИС: Парсер HTML + База данных (Web)

## Описание
Информационная система для извлечения текстовых данных из HTML-файлов, сохранения их в локальную базу данных (IndexedDB) и вывода через графический интерфейс.

## Стек технологий
- HTML5 / CSS3 (Неоновый дизайн, анимация SVG)
- Vanilla JavaScript
- IndexedDB (для хранения данных)

## Инструкция по запуску
1. Скачайте файл `index.html` из этого репозитория.
2. Откройте его двойным кликом в любом современном браузере (Chrome, Edge, Firefox).
3. **Для парсинга**: Откройте любой сайт, нажмите `Ctrl+S` и сохраните его как "Веб-страница, только HTML". Выберите этот файл в интерфейсе программы и нажмите "Спарсить".
4. Данные сохранятся в БД браузера. Поиск и удаление работают в реальном времени.

## Модули
- Модуль 1: Парсер (DOMParser, Regex)
- Модуль 2: Интерфейс парсера
- Модуль 3: Интеграция (сохранение в IndexedDB)
- Модуль 4: Скрипт вывода (запросы к БД)
- Модуль 5: Интеграция вывода
- Модуль 6: Интерфейс вывода (таблица, поиск, очистка)
- Модуль 7: Тестирование (QA, API, ручное)
